# ScreenCapture 用户手册

版本 **v0.8.0** · 适用系统：Windows 10 / 11（x64）、macOS 11+（Apple Silicon / Intel）

ScreenCapture 是一款轻量的跨平台截图与标注工具：支持全屏 / 区域 / 窗口截图、标注编辑、全局热键、系统托盘与固定到屏幕。

> Windows 部分已在真机验证；macOS 部分已完成代码实现与交叉编译检查，运行时行为（屏幕录制权限、菜单栏、全局热键）尚未实机验证，见第 13 节。

---

## 1. 安装与启动

### 方式一：绿色便携

1. 解压发布包 `ScreenCapture-0.7.0-win64.zip` 到任意目录。
2. 双击 `ScreenCapture.exe` 启动，无需安装、无额外运行库依赖。
3. 启动后主窗口打开，同时系统托盘出现图标。
4. 首次运行会创建配置文件：`%APPDATA%\ScreenCapture\config.toml`。

### 方式二：安装到本机（推荐）

在解压目录中打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
# 需要桌面快捷方式时：
powershell -ExecutionPolicy Bypass -File install.ps1 -DesktopShortcut
```

安装脚本会：

- 复制程序到 `%LOCALAPPDATA%\Programs\ScreenCapture`
- 创建开始菜单快捷方式（可选桌面快捷方式）
- 同时复制卸载脚本，便于后续清理

> 程序未做代码签名，部分杀毒软件可能提示风险，请添加信任后使用。

## 2. 三种截图方式

| 方式 | 应用内快捷键 | 默认全局热键 | 说明 |
|------|-------------|-------------|------|
| 全屏截图 | `F1` | `Ctrl+Shift+F` | 抓取所有显示器的完整画面 |
| 区域截图 | `F2` | `Ctrl+Shift+A` | 打开全屏遮罩，拖拽选择区域 |
| 窗口截图 | `F3` | `Ctrl+Shift+W` | 截取下拉列表中选中的窗口 |

窗口截图前请先点击「刷新窗口列表」，在下拉框中选择目标窗口，再点击「截取窗口」。

截图完成后会自动进入编辑器；若开启了「截图后自动复制」，原始画面会立即复制到剪贴板。

## 3. 区域选区操作

打开区域选择后，整个屏幕会变暗：

| 操作 | 说明 |
|------|------|
| 拖拽 | 拉出选区 |
| `Enter` / 双击 | 确认选区并进入编辑器 |
| `Esc` | 取消选区 |
| 方向键 | 微调选区位置 1px |
| `Shift` + 方向键 | 微调 10px |
| `Ctrl` + 方向键 | 调整选区宽高 |
| `Ctrl+A` | 全选当前显示器 |

选区时右上角显示操作提示，光标旁有放大镜（15×15），显示坐标与 RGB / HEX 色值；悬停窗口时会红色高亮窗口边界。

## 4. 编辑器

截图确认后进入编辑器，界面由两行工具栏 + 画布 + 状态栏组成。

### 4.1 工具

| 工具 | 快捷键 | 说明 |
|------|--------|------|
| 选择 | `V` | 拖拽平移画布 |
| 画笔 | `P` | 自由手绘 |
| 矩形 | `R` | 拖拽画框，可勾选「填充」 |
| 椭圆 | `E` | 拖拽画椭圆，可勾选「填充」 |
| 箭头 | `A` | 拖拽绘制带箭头直线 |
| 文字 | `T` | 点击位置弹出输入框，`Ctrl+Enter` 确定、`Esc` 取消 |
| 序号 | `N` | 点击添加 1、2、3… 圆形序号，自动递增 |
| 马赛克 | `M` | 拖拽区域打码，可调块大小 |
| 取色 | `C` | 点击画面拾取颜色，状态栏显示 HEX/RGB |

### 4.2 颜色与参数

- 颜色：8 个预设色 + 取色盘，右侧显示 HEX 值
- 粗细：1–24 px（影响画笔、形状描边、序号圆大小）
- 字号：10–72（文字工具）
- 填充：仅矩形 / 椭圆有效
- 马赛克块：4–40 px

### 4.3 画布

- 滚轮：以光标为锚点缩放（5%–1600%）
- 中键拖拽，或选择「选择」工具后左键拖拽：平移
- 左下角显示图像尺寸、缩放比例与光标坐标

### 4.4 编辑操作

| 操作 | 说明 |
|------|------|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| 撤销 / 重做按钮 | 与快捷键等效 |
| 清除标注 | 清空全部标注 |
| 保存 | 按设置中的目录 / 模板 / 格式保存（含标注） |
| 复制 | 合成标注后复制到剪贴板 |
| 固定 | 生成置顶悬浮窗（见 5.3） |
| 完成 | 结束编辑；若开启「自动保存」会先保存 |

> 保存与复制都会把标注烘焙进像素，导出的图片与画布预览一致。

## 5. 保存与输出

### 5.1 保存位置与文件名

在「设置 → 保存与输出」中配置：

- **保存目录**：目录不存在会自动创建
- **文件名模板**：默认 `Screenshot_{date}_{time}`
- **图片格式**：PNG / JPG / BMP
- **JPEG 质量**：1–100（仅 JPG 生效）

模板变量：

| 变量 | 含义 | 示例 |
|------|------|------|
| `{date}` | 日期 | `20261117` |
| `{time}` | 时间 | `153045` |
| `{datetime}` | 日期_时间 | `20261117_153045` |
| `{unix}` | Unix 时间戳（秒） | `1794850000` |
| `{index}` | 序号（3 位补零） | `001` |

文件名中的非法字符（`\ / : * ? " < > |`）会自动替换为 `_`；重名时追加 `_2`、`_3`，不会覆盖已有文件。

### 5.2 自动保存与自动复制

- **截图后自动复制**（默认开启）：截图确认后立即复制原始画面；保存时也会同时复制
- **点击「完成」时自动保存**（默认关闭）：开启后点「完成」会先保存再退出编辑

### 5.3 固定到屏幕

在编辑器点击「固定」，截图会以一个置顶无边框窗口显示：

- 拖拽窗口任意位置移动
- 双击或按 `Esc` 关闭
- 固定在当前进程内有效，退出程序后消失

## 6. 延迟截图

工具栏「延迟截图」菜单可选择全屏 / 区域 / 窗口并开始倒计时：

1. 在「设置」里选择延迟秒数（0 / 1 / 3 / 5 / 10 秒）
2. 点击「延迟截图」，选择截图方式
3. 状态栏显示剩余秒数，倒计时结束后自动执行截图

适合先切换窗口或展开菜单再截图。

## 7. 设置

点击主界面「设置」，包含：

| 分区 | 内容 |
|------|------|
| 保存与输出 | 保存目录、文件名模板、格式、JPEG 质量、延迟秒数、自动保存、自动复制 |
| 全局热键 | 区域 / 全屏 / 窗口三个热键，格式如 `Ctrl+Shift+A`、`F2` |
| 其他 | 开机自启、配置路径、浅色/深色主题 |

点击「保存并应用」后：

- 热键立即注销并按新配置重新注册
- 配置写入 `config.toml`
- 保存目录、模板、格式等立即生效

热键注册失败时会在设置窗口提示原因，例如「与『区域截图』热键重复」「已被其他程序占用」。

## 9. 配置文件

路径：`%APPDATA%\ScreenCapture\config.toml`

```toml
[general]
save_path = "D:\\Pictures\\ScreenCapture"
auto_save = false
copy_to_clipboard = true
file_format = "png"
capture_cursor = false
file_name_template = "Screenshot_{date}_{time}"
jpeg_quality = 92
delay_seconds = 3

[hotkeys]
region = "Ctrl+Shift+A"
fullscreen = "Ctrl+Shift+F"
window = "Ctrl+Shift+W"

[editor]
default_color = "#FF3B30"
default_thickness = 3.0
default_font_size = 20.0
```

格式错误会导致加载失败并回退到默认配置，删除该文件后重启即可恢复默认。

## 10. 常见问题

**Q：全局热键没反应？**
在「设置」查看热键状态；若提示占用，请换一个组合。热键只在程序运行期间有效。

**Q：托盘区找不到图标？**
Windows 11 默认折叠新图标，点击任务栏的「^」查看；或在任务栏设置中把 ScreenCapture 设为常显。

**Q：截图是黑屏 / 空白？**
部分硬件加速窗口（浏览器视频、游戏）或受保护内容无法通过 GDI 抓取，可尝试关闭硬件加速，或改用窗口截图。

**Q：中文显示为方块？**
程序会加载系统黑体/微软雅黑，若系统精简掉这些字体会无法显示中文。

**Q：保存失败？**
检查保存目录是否存在写权限，或在设置中换到用户目录（如 `D:\Pictures\ScreenCapture`）。

**Q：开机自启失效？**
移动程序位置后注册的路径失效，请在设置中取消再重新勾选。

**Q：粘贴到其他软件没有图片？**
请使用「复制」按钮（或用默认开启的自动复制）后再粘贴，部分软件只接受 PNG 剪贴板格式。

## 11. 卸载

**通过安装脚本安装：**

```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\ScreenCapture\uninstall.ps1"
# 同时删除配置（热键、保存设置等）：
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\ScreenCapture\uninstall.ps1" -PurgeConfig
```

卸载脚本会删除快捷方式、开机自启项、程序文件，并结束正在运行的进程。

**便携版手动卸载：**

1. 右键托盘图标 → 退出
2. 打开「设置」取消勾选「开机自动启动」
3. 删除程序所在目录
4. 如需清除配置，删除 `%APPDATA%\ScreenCapture` 目录

---

## 12. 已知限制

- 关闭主窗口即退出程序（最小化后热键仍可用）
- 固定窗口不支持缩放，重启程序后不会恢复
- 默认自动复制会覆盖剪贴板内容
- 截图不包含鼠标光标
- 混合 DPI 多显示器下窗口位置与坐标为实验性支持

## 13. macOS 使用说明

> 本章内容基于代码实现与交叉编译检查，**尚未在 Mac 真机验证运行时行为**。

### 13.1 构建与运行

```bash
# 安装 Xcode 命令行工具（提供系统框架）
xcode-select --install

# 构建
cargo build --release
./target/release/screencapture

# 打包 .app / zip（可选 dmg）
bash scripts/package-macos.sh
open dist/ScreenCapture.app
```

未签名产物首次打开需右键 →「打开」，或执行：

```bash
xattr -dr com.apple.quarantine dist/ScreenCapture.app
```

### 13.2 屏幕录制权限

首次截图时 macOS 会请求「屏幕录制」权限；若未弹出或误点拒绝，请手动开启：

**系统设置 → 隐私与安全性 → 屏幕录制 → 勾选 ScreenCapture**（开启后需重启应用）。

未授权时截图会失败或得到空白图像，界面与通知会提示授予权限。

### 13.3 菜单栏与热键

- 启动后菜单栏出现「取景环」图标，点击展开：全屏截图 / 区域截图 / 窗口截图 / 显示主窗口 / 退出
- 全局热键默认与 Windows 相同（`Ctrl+Shift+A` / `Ctrl+Shift+F` / `Ctrl+Shift+W`），配置写法支持 `Cmd`、`Option` 别名
- 通知通过系统通知中心显示（`osascript`）

### 13.4 路径与自启动

| 项目 | 路径 |
|------|------|
| 配置文件 | `~/Library/Application Support/ScreenCapture/config.toml` |
| 默认保存目录 | `~/Pictures/ScreenCapture` |
| 开机自启 | `~/Library/LaunchAgents/com.screencapture.app.plist` |

### 13.5 macOS 已知限制

1. 全屏截图不包含自身窗口的排除逻辑（Windows 上会临时把主窗口移出屏幕，macOS 暂未实现）
2. 多显示器、混合缩放比例下的坐标换算未实机验证
3. 区域选择覆盖层、固定到屏幕、托盘菜单、全局热键尚未实机验证
4. 应用未签名 / 未公证，分发时需自行处理 Gatekeeper 提示
